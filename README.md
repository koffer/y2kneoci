## 🇬🇧 English

### Description
**y2kneoci** is a retro, Y2K, and NeoCities-inspired theme built for the Hugo Static Site Generator. It brings back the classic web aesthetic with a vibrant pink color palette, double borders, and 3D beveled navigation menus, updated with modern, semantic, and clean HTML code. 

### Features
* **Retro Aesthetic:** Authentic Y2K / NeoCities visual portal layout featuring strict double borders and maroon typography.
* **Multiple Backgrounds:** Includes CSS classes for various background patterns such as Checkered Pink, Modern Dots, and Solid Neutral.
* **Clean & Semantic:** Zero inline styles. All HTML is cleanly separated from the CSS for easy maintenance.
* **Component-Based Layout:** Built using Hugo's modular `_partials` system for the navigation, sidebar, and head tags.
* **Simulated Admin UI:** Post pages (`single.html`) feature classic simulated tabbed navigation to emulate retro CMS environments.

### Descripción
**y2kneoci** es un tema de estilo retro, inspirado en la estética Y2K y NeoCities, creado para el generador de sitios estáticos Hugo. Recupera la estética web clásica con una paleta de colores rosa vibrante, bordes dobles y menús de navegación con efecto biselado 3D, todo ello actualizado con código HTML moderno, semántico y limpio.

### Características
* **Estética retro:** Diseño visual auténtico tipo portal Y2K/NeoCities, con bordes dobles definidos y tipografía en color granate.
* **Fondos múltiples:** Incluye clases CSS para diversos patrones de fondo, como cuadros rosas, puntos modernos y colores neutros sólidos.
* **Código limpio y semántico:** Sin estilos en línea (*inline styles*). Todo el código HTML está claramente separado del CSS para facilitar el mantenimiento.
* **Diseño basado en componentes:** Construido utilizando el sistema modular `_partials` de Hugo para la navegación, la barra lateral y las etiquetas del encabezado (*head*).
* **Interfaz de administración simulada:** Las páginas de artículos (`single.html`) cuentan con una navegación clásica simulada mediante pestañas para emular los entornos de los CMS de antaño.
